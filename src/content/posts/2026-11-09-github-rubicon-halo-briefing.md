11 月上旬，AI 行业的两条主线同时出现了「基础设施化」的信号：AI coding 侧，GitHub 开始为智能体大规模协同重构底层 Git 架构，而两份重磅研究则给狂飙的智能体效率叙事泼了冷水；具身智能侧，苹果罕见地公开了人形机器人自主控制系统 HALO 并开源全套代码，国内的进博会与实景实训赛则把人形机器人从展台推向真实工作场景。以下 5 条值得展开。

## GitHub 公布新存储架构 Rubicon：为 5000 个智能体同仓协作做准备

**发生了什么**：据 Superpower Daily 报道，GitHub 在 GitHub Universe 大会上公布了代号「Rubicon」的全新 Git 存储架构，面向 AI 智能体大规模协同开发场景，目前已启动小范围内测，计划明年初逐步扩大开放。官方介绍称其具备每秒数千次写入处理能力、读取按需水平扩展；内部压力测试显示，单仓库最多可支持 5000 个智能体同时协作，承受每秒 7200 次代码推送。

**为什么值得关注**：作为对照，当前 GitHub 平台业务繁忙的仓库每秒写入峰值大多只有数十次。随着智能体全天候高并发承担研发任务，过去「短时脉冲」式的流量正在变成常态化高吞吐——这不是应用层的改良，而是版本控制基础设施的代际更换。对自建 Git 服务的企业来说，这也预示着未来一年 Git 服务器选型和容量规划都要按「人机混合、机器为主」的负载重新估算。

## Co-Design Bench：顶级编程智能体真实任务完整完成率仅 26.4%

**发生了什么**：一项名为 Co-Design Bench 的新基准测试显示，面对真实世界的前端改造类任务（布局、设计、交互、内容交织出现），表现最好的模型（GPT-6 Astra）也只完整完成 26.4% 的任务，Claude Opus 5 与 Qwen3.8-Max 位列其后，Grok 4.6 在十款受测模型中垫底。更关键的发现是「模型 + 运行环境（harness）」的强耦合：同一个 Qwen3.8-27B 在不同 harness 下得分能差 19 个百分点。

**为什么值得关注**：这与 METR 此前的研究互相印证——AI 代码的实际采纳率比 SWE-bench Verified 分数低约 24 个百分点。结论很朴素：只看模型排行榜选型会系统性高估工具能力，正确的姿势是把模型和 harness 当成一对来测，且要用自己团队真实的「混乱型」需求。对正在给团队选 coding agent 的负责人，这份榜单比任何厂商发布会都更有参考价值。

## 哈佛研究修订版：AI 让代码多写 44%，但评审成了新瓶颈

**发生了什么**：哈佛经济学家 Chen 与 Stratton 11 月 7 日发布了 AI coding 研究的修订版，基于 Jellyfish 数据覆盖 655 家公司、72 万名开发者（2021.1—2026.8）。在已有 AI 助手的基础上再引入 coding agent 后，12 个月内 PR 数量增长 35.7%、代码行数增长 44%，解决的 Jira issue 也提升了 13.7%（边际显著）；但代码评审时间从提交到批准拉长了 56.1%，人均评审意见数增加 38.6%，而工程团队人数没有可检测的变化（−2.6%，不显著）。

**为什么值得关注**：代码产出增长是「完成工作」增长的两到三倍，瓶颈清晰指向了人类评审环节——AI 把写代码加速了，但评审队列在变长。论文修订版还给出了到 2031 年的就业情景推演（−10.3% 到 −76.2%），分岔点取决于评审效率能否跟上。对工程管理者，直接的行动启示是：引入 agent 的同时必须同步投资评审侧的自动化与流程改造，否则产出只会堆在队列里。

## 苹果公开人形机器人「大脑」HALO：跑在宇树 G1 上，单项任务成功率 91%

**发生了什么**：当地时间 11 月 4 日，苹果研究团队在 arXiv 提交论文《Perceptive Humanoid Motion from Simulation》，披露人形机器人自主控制系统 HALO，并公开了数据生成、训练与部署的全套代码。系统采用三层架构：上层 VLM 任务编排（默认千问 Qwen3.6-35B-A3B，跑在机器人背上的 Mac mini M4 Pro 里，可离线工作），中层动作生成（Qwen3.5-2B 冻结编码器 + DiT 解码器，每秒重规划约 3 次），底层为强化学习训练的动作跟踪器（每秒 50 次）。在 6 个未预先建图的真实环境中 360 次单项任务测试平均成功率 91%，组合任务成功率 70%。

**为什么值得关注**：三点信息量。其一，苹果首次明确披露在人形机器人方向的系统级成果，且选择开源——对标的是 Figure、特斯拉们普遍闭源的路线；其二，「开源 VLM + 仿真合成数据（250 张 H100 约 48 小时）+ 实机部署」的完整链路跑通，为中小团队提供了可复现的参考架构；其三，苹果大方承认了短板：依赖视觉、缺乏触觉感知，遮挡场景下接触类任务表现下降——这恰好和国内学界「最后几毫米」的判断一致。此外，宇树同期与光轮智能达成战略合作，叠加本篇的 G1 出镜，其本体正在成为海外研究团队的默认验证平台。

## 具身智能从「秀表演」转向「能干活」：进博会实景化 + 马鞍山实训赛开赛在即

**发生了什么**：第九届进博会上，人形机器人展示从舞蹈表演转向真实工作场景：宇树与智元同台演示打乒乓球、泡功夫茶、酒店服务，星动纪元为 DHL 展台提供快递分拣技术支持，智元 6 台 G2 完成 24 小时门店挑战、累计执行 1730 项任务。政策侧，工信部副部长熊继军在虹桥论坛表示整机产品正从「能跑会跳」向「能想会干」升级，今年上半年人形机器人产量已超 4 万台、全年预计突破 10 万台。11 月 16 日起，人形机器人与具身智能实景实训挑战赛将在马鞍山举办，把「考场」搬进制造、物流、酒店、商超等真实场景，设 13 个赛项。

**为什么值得关注**：产业验证方式正在换代——从展台演示转向真实作业数据积累，这恰恰回应了王兴兴在虹桥论坛上的判断：当前瓶颈不在多模态模型的理解规划，而在「模型与物理世界交互衔接的最后几毫米」。实景实训赛以赛促产、以真实场景产出训练数据的思路，与苹果 HALO「仿真合成 + 实景验证」的路线殊途同归。资本与供应链排产都在提速，2026 年被多家机构视为人形机器人 0-1 跨越的关键节点。
