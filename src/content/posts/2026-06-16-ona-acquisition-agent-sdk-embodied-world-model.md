本周，AI 编程智能体领域的关键叙事从「能力验证」转向「基础设施与治理」——智能体要真正成为持久工作者，需要安全可控的运行环境、合理的计费模型和企业级治理能力。具身智能侧，世界模型从「旁观预测」走向「交互决策」，星源智的 ω-EVA 为机器人装上了行动前先预演后果的"大脑"。

## 发生了什么

- **OpenAI 收购 Ona**（6 月 11 日）：为 Codex 编程智能体提供安全、持久的云端执行环境，使其能承担运行数小时乃至数天的长周期任务。
- **Anthropic Agent SDK 计费拆分**（6 月 15 日生效）：程序化智能体用量不再占用交互式订阅额度，改为按用户每月发放 Agent SDK 专属积分（Pro $20/月，Max 5x $100/月，Max 20x $200/月）。
- **JFrog 发布 Claude Code 安全治理插件**（6 月 10 日）：将软件供应链治理能力（制品扫描、元数据管理、MCP 注册表管控）集成进 Claude Code，智能体修改代码时同步遵守企业安全策略。
- **星源智发布全球首个具身交互世界模型 ω-EVA**（6 月 13 日）：在第八届北京智源大会上发布，首创「预演、验证、行动」决策闭环，让机器人通过行动前预判后果、自主优化动作，打破传统世界模型仅做预测的局限。

## 要点解读

### OpenAI 收购 Ona：Codex 从「临时工」变成「长工」

OpenAI 本周四宣布收购初创公司 Ona。Ona 专注于为 AI 智能体构建安全、预配置的云端运行环境，其核心技术是让智能体在客户可控的环境中持久运行——拥有作用域凭证、状态持久化和企业级安全管控。

这为什么重要？当前 Codex 等编程智能体本质上还是"随叫随到、干完就走"的临时工模式：你发一条指令，它执行，然后状态归零。但真实的企业工程任务（大规模重构、持续集成流水线维护、跨仓库依赖升级）往往需要数小时甚至数天持续运行，中间需要访问内部系统、持有有效凭证、维护中间状态。Ona 的技术正好补上了这块地基。

结合 OpenAI 此前的收购线索——2025 年 9 月收购 Xcode AI 助手 Alex Codes，2026 年 3 月计划收购 Python 工具商 Astral——可以看到 OpenAI 正在系统性地为 Codex 构建全栈开发者服务工具链。而 S-1 招股说明书的秘密提交（6 月 8 日）意味着这些布局将加速商业化变现。

### Anthropic Agent SDK 计费拆分：消除规模化落地的经济性障碍

6 月 15 日起，Anthropic 对 Claude 生态的计费模型做了关键拆分：

| 套餐 | 月度 Agent SDK 积分 |
|------|-------------------|
| Pro | $20/月 |
| Max 5x | $100/月 |
| Max 20x | $200/月 |

此前，通过 Claude Agent SDK、`claude -p` 非交互模式、Claude Code GitHub Actions 等方式调用的程序化智能体用量，会消耗用户的交互式订阅额度。这导致一个尴尬局面：你的 Claude Code 自动化跑得越多，你正常聊天可用的额度就越少，两者互相挤占。对于想要把智能体接入 CI/CD 管线的团队来说，这是规模化落地的直接障碍。

拆分后的逻辑很清晰：交互式使用（你在终端里手动 `claude` 对话）和自动化使用（Agent SDK 驱动的持续任务）走不同的额度池，互不干扰。积分按用户独立计算不可共享；耗尽后按 API 费率计费。实操建议：实验性用量走订阅积分，生产级持续自动化应切换至 Claude Platform 按需付费 API Key。

### JFrog × Claude Code：供应链安全进入智能体执行流

JFrog 发布插件，将其软件供应链治理能力集成进 Anthropic 的 Claude Code。这意味着当 Claude Code 在你的代码仓库中执行修改时，它可以同步遵守企业级安全策略——制品扫描、来源约束、MCP 注册表管控等。

这是本周最典型的「安全厂商将治理能力嵌入智能体控制平面」的案例。AI 编程智能体进入企业生产环境，最大的顾虑之一就是它改代码时"不知道边界"——可能引入未审核的依赖、绕过安全扫描、或者引入合规风险。JFrog 的做法是把治理规则从"事后审计"前移到"执行时同步"，让智能体在行动中就受到约束，而非事后追责。

这预示着一个趋势：更多的安全与合规能力将以内嵌方式出现在智能体工具链中，而非作为外部检查环节。

### 星源智 ω-EVA：世界模型从「看」到「做」的关键跨越

6 月 13 日，在第八届北京智源大会现场，北京星源智机器人科技有限公司发布了全球首个具身交互世界模型 ω-EVA。

传统世界模型的局限在于：它只是"看"——预测环境状态如何变化，但不参与决策。ω-EVA 的突破在于首创「预演、验证、行动」决策闭环：

1. **预演**：机器人在行动前先在世界模型中模拟动作后果
2. **验证**：评估预演结果是否满足目标约束
3. **行动**：验证通过后执行真实动作，失败则动态修正

现场演示中，星源智用一块被随机打乱的华容道棋盘展示了这一能力。华容道看似逻辑推理题，但对机器人而言它是连续决策问题——每一步移动都需要手部精确操控、空间推理和序列规划。ω-EVA 让机器人在出手前先"想清楚"，大幅降低了试错成本和作业风险。

结合近期具身智能赛道的资本热度——千寻智能 2 个月完成三轮融资估值超百亿元，星源智成立 10 个月融资约 10 亿元，灵心巧手完成 B/B+ 轮——技术突破与资本加码正在形成正循环。正如智源大会上多位专家所言，未来两三年是具身智能走向规模化商用的关键窗口期。
