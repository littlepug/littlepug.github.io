6 月末，AI 编程与具身智能两条主线同时出现标志性进展。OpenAI 用 GPT-5.6 Sol 刷新了编程智能体的能力上限，中科南京软件院则一次性拿出了模型、编程 Agent 和机器人三款成果，把产学研协同落地的节奏拉快。资本和政策层面也在同步确认：具身智能不再是"故事期"，而是进入规模化验证。

## 发生了什么

- **OpenAI 发布 GPT-5.6 系列**（6 月 26 日）：旗舰模型 Sol 在 Terminal-Bench 2.1 智能体编程基准中超过 Anthropic Claude Mythos 5，并支持 Max、Ultra 等更高阶推理模式；定价为每百万输入 Token 5 美元、输出 Token 30 美元，约为 Claude Fable 5 的一半。ChatGPT、Codex 及 API 未来将逐步升级至 GPT-5.6 架构。
- **中科南京软件院发布核心 AI 成果**（6 月 26 日发布，6 月 29 日报道）：集中推出 Focus VLA 具身智能模型、Zenk 决策智能体、BoCoder 编程智能体，以及第二代具身智能机器人 Armstrong Pro。
- **2026 上半年国内具身智能融资超 460 亿元**（6 月 16 日）：288 起融资事件，头部公司集中效应明显，千寻智能三个月吸金 45 亿元、星源智十个月融资 10 亿元。
- **WorkOS 发布 Auth.md**（6 月 28 日）：面向 AI Agent 的服务注册开放协议，让 Agent 无需传统浏览器表单即可发现注册流程、申请权限并获取安全凭证，Cloudflare、Firecrawl、Resend 等已采纳。

## 要点解读

### GPT-5.6 Sol：编程智能体基准再易主

OpenAI 此次发布最值得关注的是三件事叠加：能力、价格、开放方式。

**能力层面**，Sol 在 Terminal-Bench 2.1——一个专门评估智能体在终端环境中执行复杂编程任务的基准——上超过 Anthropic Claude Mythos 5。这相当于在 AI 编程 Agent 的"主考场"里重新夺回了第一名。Sol 还被定位为面向复杂推理、智能体、科研及软件开发的旗舰模型，并支持 Max、Ultra 等更高阶推理模式。

**价格层面**，Sol 定价为 5 美元 / 百万输入 Token、30 美元 / 百万输出 Token，约为 Anthropic Claude Fable 5 对应价格的一半。OpenAI 正在用"同等能力、更低价格"的策略，直接冲击 Anthropic 在高端编程模型市场的定价权。

**开放方式层面**，GPT-5.6 目前仅向少数"可信合作伙伴"开放预览，这是应美国政府要求建立前沿 AI 模型安全评估机制的一部分。OpenAI 表示希望建立可重复执行的监管流程，而非长期逐案审批。这一点比模型本身更具信号意义：前沿模型的发布已经开始受到政府安全审查的系统性影响，"先发布、后治理"的时代正在结束。

```text
GPT-5.6 三档模型定位
─────────────────────────────────
Sol   │ 复杂推理、智能体、科研、软件开发
Terra │ 日常办公场景的性能与成本平衡
Luna  │ 轻量化、低延迟场景
```

对开发者的直接影响：如果你正在用 Claude Code 或 Codex 做复杂代码重构、智能体工作流，Sol 一旦全面开放，可能成为切换成本最低的更强选项。建议提前关注 GPT-5.6 在 Codex 中的集成节奏。

### 中科南京软件院：一次集齐"大脑 + 工具 + 身体"

在 2026 南京软件大会上，中科南京软件院联合江苏博云、智往未来等企业发布四项核心成果，覆盖了 AI 编程与具身智能的关键环节。这不是单个产品的发布，而是一套"从模型到机器人"的落地组合。

**Focus VLA 具身智能模型**：由中科南京软件技术研究院推出，可预判机器人动作意图，提升设备作业精度与稳定性，破解复杂场景作业瓶颈，支撑工业、物流场景落地。VLA（Vision-Language-Action）模型是 2026 年具身智能的热门路线，它把视觉理解、语言指令和动作执行统一在一个模型里，让机器人能更自然地接收人类指令并执行物理操作。

**Zenk 决策智能体**：融合大模型与决策模型，搭建行业知识库，实现可解释、可追溯的推理，并配套轻量化部署方案。对企业来说，这意味着智能决策系统可以脱离云端强依赖，在本地或边缘侧运行。

**BoCoder 编程智能体**：由江苏博云发布，依托云原生与 AI 工程化积累，面向工业、金融、政务领域提供安全可控的一站式 AI 方案。这一定位与海外 Cursor、Codex 等产品形成差异：BoCoder 更强调行业 know-how 和私有化部署能力。

**Armstrong Pro 第二代具身智能机器人**：由智往未来发布，是该研究院孵化企业，专注于仓储物流拣选场景。初代 Armstrong 已在国内头部物流企业完成多场景实测，新款 Armstrong Pro 成功入驻世界 500 强外企仓库，实现从技术验证到商业应用的关键一跃。

```text
中科南京软件院成果矩阵
─────────────────────────────────
Focus VLA  │ 具身智能模型（大脑 + 感知 + 动作）
Zenk       │ 决策智能体（可解释推理）
BoCoder    │ 编程智能体（行业 AI 方案）
Armstrong Pro │ 具身智能机器人（仓储物流落地）
```

值得关注的是，活动现场还启动了"中科·智原"OPC 产业生态创新中心，并签署了多项产学研、产融合作协议。这说明南京正在把科研能力、产业场景和资本力量串成一条闭环，这种模式很可能是国内 AI 产业化落地的一个有效样本。

### 460 亿融资：具身智能进入"量产兑现期"

钛媒体 6 月 16 日报道，2026 年上半年国内具身智能及机器人领域共发生 288 起融资事件，涉及 226 家企业和 274 家投资机构，披露融资总额超 460 亿元。这个数字已接近 2025 全年 554 亿元的水平。

更关键的是资金结构：七成资金流向约 20 家头部公司。千寻智能三个月吸金 45 亿元、星源智十个月融资 10 亿元，头部公司的"弹药储备"正在快速拉开与第二梯队的差距。

北京智源大会具身智能 CEO 论坛上，千寻智能 CEO 韩峰涛直言："如果今年你还没有搞到行业头部的资金量和估值，可能明年就很难了。"星源智 CEO 刘东则给出更具体的比例：储备资金与商业化落地七三开。两句话合在一起看，行业的共识已经清晰：具身智能的窗口期正在从"融资竞赛"转向"落地竞赛"。

把这个判断放在更大的背景里：

- 工信部、国资委 6 月联合启动 2026 年度人形机器人与具身智能实景实训专项行动，目标年底形成百个以上高价值应用场景；
- 宇树 2026 年预计出货 5,500 台，智元目标下线 5,000 台；
- 中信建投等券商研报判断 2026 年将是人形机器人垂类应用大年。

资本、产能、政策三条线在同一时间节点交汇。460 亿融资不是终点，而是量产兑现期的启动资金。

### Auth.md：补齐 Agent 经济的"身份层"

WorkOS 6 月 28 日发布 Auth.md，一个面向 AI Agent 的服务注册开放协议。它的核心问题是：注册表单是为人类在浏览器里设计的，Agent 怎么自动完成服务注册？

Auth.md 的解决方案是用一个 Markdown 文件定义注册流程、所需权限、凭证发放方式和安全约束。Agent 可以读取这个文件，自动完成注册、申请 scopes、获取用户级凭证。这听起来是一个基础设施细节，但它是 Agent 经济真正运转的前提：没有统一的"身份层"，每个 Agent 都要写一堆适配器，规模化无从谈起。

目前已经确认采纳的厂商包括 Cloudflare、Firecrawl、Resend、Monday.com、Zuplo、NanoGPT 和 AgentMail。一个有趣的对比是：OpenAI 的 MCP 正在统一 Agent 与工具的连接标准，而 Auth.md 正在统一 Agent 与服务的身份注册标准。两者叠加，Agent 的"连接能力"和"身份能力"才完整。

```text
Agent 基础设施的分层
─────────────────────────────────
MCP      │ 工具调用 / 服务连接标准
Auth.md  │ 服务注册 / 身份凭证标准
```

对开发者的意义：如果你正在构建 Agent 产品，除了关注模型能力和工具链，也应该把身份注册和权限管理纳入设计。Auth.md 可能成为 Agent 之间安全互操作的事实标准之一。
