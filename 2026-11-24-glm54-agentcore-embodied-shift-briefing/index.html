GLM-5.4 发布：泛 Coding 与具身换挡

2026-11-24 · 11 min 阅读

11 月 23 日至 24 日，AI 领域的两条主线同时出现了”结构级”的变化：coding 一侧的重心从”模型能不能写对”转向”运行时、权限与供应链能不能管住”，具身智能一侧则从”专用机器人堆栈”退回”主模型直接出动作”。本文筛出 5 条值得细读的动态，另有几条短讯附在文末。

智谱 GLM-5.4：用循环计算换推理深度

发生了什么

11 月 23 日晚，智谱发布新一代旗舰模型 GLM-5.4，首次采用 Loop Transformer 架构。做法是把已训好的 750B 级基座按 28 层一组做两轮循环推演——同一组共享权重的层在一次计算中执行两遍，第二轮在上一轮的隐状态上继续细化结果，从而在不增加参数量的前提下获得更深的网络。智谱称 GLM-5.4 的智能水平可对标 2 万亿至 3 万亿参数级模型。

同时，新模型补上了视觉输入，并把 coding 能力外推到智谱所说的”泛 Coding”：Code to Video、Code to Game、Code to 3D、Code to Image，并支持与第三方建模软件联动。官方演示里有纯数学几何 + 自定义着色器从零生成 3D 微距场景、用前端代码实时画出视频短片这类用例。

开放节奏与硬指标

  • 开放范围：即日起向 GLM Coding Plan 全量用户开放，同步上线 ZCode、Trae、WorkBuddy、Qoder 等编码平台；Coding Plan V2/V3 与团队版额度提升至 1.5 倍
  • API：待安全评估后上线；模型权重计划以”负责任的方式”开源
  • 速度：官方口径为非高峰最高 200 token/s，高峰 70–80 token/s
  • 评测：200 个真实场景的编程实战评测（官方内部数据，暂无第三方榜单验证）；智谱自评”仍是 Coding 体感最强的国产模型”，长程任务与视觉复刻表现突出
  • 下一代：管理层预告第四季度推出约 3 万亿参数旗舰（市场推测为 GLM-5.5，时间点在 12 月前后），规模约为现有基座的 4 倍

值得关注的点

  • 架构路线的第二次分岔。过去两年提升智能的主流做法是堆参数、堆数据、堆 RL；Loop Transformer 走的是”堆计算深度”，用更少的权重换更长的思考链。它和把基座直接改造成循环结构”复用已训权重”的做法，恰好绕开了重训的成本——这让”老基座再榨一轮”成为一条现实路径。
  • 官方也在承认代价。智谱坦言新架构容易陷入过长的”雷霆大思考”，且没有回答”不同难度任务该怎么分配计算量""循环轮数继续加、规模继续扩收益如何变化”这两个关键问题。换句话说，Loop 目前更像一次对”计算深度”的可行性验证，而不是终局架构。
  • “泛 Coding”是对 coding agent 能力边界的一次重新划线。如果代码成为连接文本与空间、视频、3D 的通用接口，那么评测 coding 能力的标尺就不该只是 SWE-bench 式的修 bug，而要包含”用代码构建一个可运行的世界”。
  • 配套的国产算力进展也值得一提：摩根大通研报称智谱已实现 10 万卡级国产芯片规模化推理，GLM-5.3-Flash 在国产芯片上的推理毛利率已转正。

三家终端 coding agent 同周改默认值，agent 运行时成了新攻击面

发生了什么

11 月 19–20 日，三大终端 coding agent 在同一周内密集发版（截至 11 月 23 日仍为各自最新稳定版）：

工具版本关键变化
Claude Codev2.1.328 / 329 / 330三次共 416 条变更、280 处修复；Auto Mode 在 Bedrock / Vertex / Foundry 上默认开启；/loop 延长至 30 天；内置 easel 图表
OpenAI Codex CLIrust-v0.171.0GPT-6.2 Sol 成为目录默认模型；TUI Workspace 默认开启
Gemini CLIv0.69.0 / v0.70.0修补 shell 审批、策略匹配、系统 MCP 三处安全缺口

同期还有一起直接影响 agent 运行时的供应链事件：微软 agent-framework 的 PyPI 包 1.26.1 / 1.26.2 两个版本被上传恶意代码，内含 Python .pth 启动钩子以窃取凭据，随后被 PyPI 隔离。

值得关注的点

  • 默认值变更比新功能更危险。Code Mode 下不再对脚本输出执行 UserPromptSubmit hooks，PreToolUse hook 报错也不再自动阻断工具调用——这两条都会静默改变既有的安全护栏语义。企业如果要求人工审批，必须显式设 disableAutoMode 或把 permissions.defaultMode 钉回 default（注意：项目级 .claude/settings.json 里写 auto 会被静默忽略）。
  • 别随手升 2.1.329：该版本移除了 max_tokens 超过上限时的自动重试，次日 2.1.330 又回滚了。升级路径直接跳 330；同时 Cowork v6.28899.6 要求远端 SSH 主机的 Claude Code ≥ 2.1.330，否则 SSH 会话起不来。
  • agent 运行时已进入”供应链攻击”射程。以前大家关心 prompt injection，现在要关心 pip install 装进来的启动钩子。CI 镜像、构建机、开发笔记本上的 agent 都持有凭据，一次投毒就可能横向扩散。实践中应该做的是：锁定 lockfile、在 CI 层封禁已知恶意版本、把 agent 的凭据换成短时效令牌。

AWS Bedrock AgentCore 运行时升级：把”跑得起”变成可算的账

发生了什么

AWS 宣布升级 Amazon Bedrock AgentCore 的运行层：

  • 算力：每会话最多 8 vCPU / 32 GB 内存（约为上一版的 4 倍），容器镜像上限 10 GB
  • 内存：agent 释放内存后几分钟内即可回收，空闲 agent 可缩容到零；交互之间存在自然停顿的多轮对话 agent，单会话内存消耗最高降低 68%
  • 计价：引入基线定价——为每个会话设定最低内存分配，工作负载可按需突增到基线的 4 倍
  • 隔离范围扩展：从”计算隔离”延伸到 agent 执行过程中访问与生成的数据，支持 FUSE 动态挂载，把 agent 的工作内容落盘到文件系统（含 S3 桶）

值得关注的点

HFS Research 的 Ashish Chaturvedi 给出的判断很准：“编译大型代码库的编程 agent、加载完整网页的浏览器 agent、在本地跑小模型的 agent，都已经超出了此前的会话规模限制”——开发者只能笨拙地拆任务或者把工作搬出隔离环境。这次升级直接对准的就是这三类场景。

对做 agent 产品的团队来说，真正的信号在计价模型：基线 + 突增意味着”常驻但多数时间在等模型响应”的 agent 第一次可以被合理地定价。此前这类工作负载的云成本基本无法预估，是 agent 从 demo 走向生产的主要拦路石之一。空闲缩零 + 68% 内存下降，配合基线定价，实质上是把 agent 的运营成本从”按月租机器”改成”按会话算账”。

OpenAI 撤销独立机器人团队：让主模型直接出动作

发生了什么

  • OpenAI 撤销了独立的机器人团队，相关研究并入主模型团队；官方口径是 GPT-6.2 Astra 已能直接承担部分机器人任务
  • XDOF 公布的 Ember-0 基准显示：GPT-6.2 Astra 在双臂机器人 16 项任务上综合成功率 41.2%（上一代 19.6%），可完成打结、展开 T 恤等柔性操作
  • 英伟达的内部测试更激进：Astra 直接生成动作成功率 66.3%，接入 Codex 后升至 74.8%——但仍不足以支撑产线级部署
  • 资本侧同期出现海外今年最大单笔：Genesis AI 完成 5 亿美元 A 轮，投后估值 35 亿美元，英伟达与 AMD 风投参投，计划 2027 年量产

值得关注的点

撤销独立机器人团队不是”放弃具身”，而是技术路线的收敛：过去两年主流的做法是”VLM 做感知 + 专用策略网络/VLA 做动作”，堆一套独立堆栈；OpenAI 的选择是把动作生成直接压进通用模型，赌 scaling 能覆盖机器人的特殊性。

但这个赌注现在还差得很远。41.2% 与 74.8% 这两个数字放在产线语境里都不及格——物流分拣场景对成功率的要求通常在小数点后两位。这也解释了为什么 2026 年具身智能的资本热点集中在大脑、数据、灵巧手等上游环节，而不是本体：本体已经不是瓶颈，让模型可靠地出动作才是。

对工程师的启示是：如果主模型真的能直接出动作，那么具身团队的核心资产会从”模型”迁移到”数据闭环 + 评测基准”。Ember-0 这类基准的出现，本身就是这个迁移的先兆。

国产具身：蚂蚁首次领投本体，人形进入半导体核心工序

发生了什么

  • 至简动力（Simplexity Robotics）完成 1 亿美元 Pre-A 轮，蚂蚁集团领投，阿里、腾讯、红杉中国、蓝驰创投等老股东全部跟投，投后估值 16 亿美元（约 107 亿元）。公司 2025 年 7 月成立，创始班底来自理想汽车智驾核心团队，董事长王凯为前理想 CTO；押注”世界模型 + VLA 一体化”，已开源多模态时序世界动作模型 SimpleWAM。融资同日发布第二款轮式人形 iX，首款 i7 Pro 已于 7 月完成首批百台交付
  • 智元精灵 G2 进入长电科技上海临港工厂，在芯片测试车间承担料盘上下料——国产人形机器人首次进入半导体制造的核心工序

值得关注的点

这两件事放在一起看，指向同一个判断：具身的估值锚正在从”故事”换成”工程能力与真实工位”。

至简动力的特殊性不在模型，而在”智驾班底整体平移”——量产工程能力（标定、可靠性、供应链、交付）在具身赛道是稀缺品，这也是 16 亿美元估值的真实依据。蚂蚁首次领投本体，意味着入口级平台开始下注硬件，而不只是做上层应用接入。

智元进封测产线则是另一种验证：半导体车间对洁净度、节拍、稳定性的要求远高于仓储物流，能进去本身就是一次能力背书。后续该盯的不是”进了哪家厂”，而是良率影响、人工接管率、以及在多班次连续运行下的在线率。

其他值得一看

  • 华为云 CloudRobo-WM1.2（11/16 发布并开源）：首款昇腾原生具身世界模型，采用共享世界模型骨干 + 原生 DualAct 架构，在 RoboTwin 2.0、Libero Pro 2.0 两项评测中均列第一，11/30 开放权重与后训练代码。更有信息量的是生态数据：80% 的中国具身智能企业已选择昇腾云，CloudRobo 平台聚集 1.65 万名开发者、230 多家企业与高校。
  • 工信部 5 项人形机器人行业标准 11 月 16 日起实施，首次建立 L0–L5 分级，并统一零部件与训练数据口径——这是行业从”各说各话”走向可比的关键一步。
  • 政策端：发改委、民政部、卫健委、教育部 11 月 23 日印发《“一老一小”服务体系建设实施方案》，明确鼓励养老场景的智能体、服务机器人、智能穿戴与外骨骼产品。
  • 马斯克口径：Optimus 预计 12–18 个月内能完成倒垃圾、洗碗并把碗碟收进橱柜等多步骤家务，先重工业再家庭。同比之下，Y Combinator 系与国内厂商的公开时间表普遍更保守，这条信息建议当作”方向”而非”排期”看待。
  • 资本市场：11 月 23 日人形机器人板块普涨，宇树科技-W、华阳智能 20% 涨停，埃斯顿、亿嘉和、北特科技、天奇股份等多股涨停。
  • Anthropic 上市后遇冷：11 月 19 日以 83 美元发行价登陆纳斯达克，含超额配售与 260 亿美元私募配售共募资约 1195 亿美元，创全球纪录；随后连续走弱逼近发行价，多位债券基金经理预计其信用评级落在 BB 区间。算力承诺约 9000 亿美元与融资结构的错配，是整个 AI 生态都要面对的隐忧。

小结

这一天最值得记住的两个转向：一是 coding 的竞争重心从模型能力下沉到运行时治理——默认权限模式、hook 语义、供应链完整性，这些”不性感”的东西正在决定 agent 能不能进生产；二是具身智能开始向通用模型收敛——OpenAI 撤团队、Astra 直接出动作、资本涌向上游，都在说明本体不再是壁垒，“让模型可靠地在真实工位上干活”才是。至于 GLM-5.4 的 Loop Transformer，它提出的问题（计算量怎么分配、循环几轮最划算）可能比它给出的答案更有价值。
