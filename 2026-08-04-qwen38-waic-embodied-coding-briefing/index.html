Qwen 3.8-Max 自主编程 16 天，具身智能告别秀场

2026-08-04 · 7 min 阅读

发生了什么

8 月初，AI 编程与具身智能两条主线同时出现标志性节点。AI Coding 方面，阿里巴巴发布 Qwen 3.8-Max，以 2.4 万亿参数稀疏 MoE 架构实现了「从空文件夹自主编程 16 天交付可用框架」的演示，并宣布下周开源权重——这是国产大模型在长周期自主编程能力上的最强信号。与此同时，GPT-5.6 Sol 与 Claude Opus 5 在 Terminal-Bench 2.1 上以不到 0.5 分之差并驾齐驱，AI Coding Agent 市场进入贴身肉搏阶段。具身智能方面，WAIC 2026 闭幕带来一个清晰的行业拐点：参展企业翻倍、真机超 300 台，机器人从「表演才艺」转向「产线干活」；银河通用 Galbot S1 在宁德时代产线连续作业超 3 个月，成为全球首个新能源产线常态化自主作业的人形机器人。

Qwen 3.8-Max：从空文件夹自主编程 16 天，下周开源

8 月 3 日，阿里巴巴正式发布 Qwen3.8-Max，这是 Qwen 系列迄今最大的旗舰模型：

  • 架构与规模：2.4 万亿总参数，每 token 仅激活 95B，采用稀疏混合专家（MoE）+ 混合注意力机制
  • 上下文与多模态：1M token 上下文窗口，原生视觉能力
  • 基准成绩：Text Arena 第 5、Vision Arena 第 2、CodeArena 第 4；PaperBench 93.0 分（对比 Fable 5 为 88.8）
  • 定价：国内 ¥12/百万输入 token、¥36 输出、缓存命中 ¥1.5；国际价格约为 Opus 5 的 40%（输入）和 24%（输出）

最引人注目的是官方演示：任务设定为「从空文件夹构建一个自进化 Agent 框架」，Qwen3.8-Max 独立运行了约 16 天的工程循环——生成代码、测试、预览、读取日志、融入用户反馈和社区实践——最终交付了名为 oh-my-cli 的可用自进化 Agent 框架，已在 GitHub 开源并公开完整操作历史。此外，团队还报告了 125 小时自主研究运行（复现已发表论文并将 AIME24 提升 2.7 分）和一个量化工作流（协调约 330 个子代理完成约 6000 次因子回测）。

同日，阿里巴巴还发布了 QwenWork，一款整合 Qwen 模型能力的职场 Agent 产品，提供 PC 客户端和钉钉集成。模型权重（Qwen3.8-Max 及 Qwen3.8-27B）计划于下周开放。

值得关注的原因：16 天自主编程是长周期 Agent 能力的里程碑。此前类似演示多在数小时量级，Qwen3.8-Max 把「AI 独立交付完整项目」的时间线拉到了「周」级别。加上开源承诺和极具竞争力的定价，这将对闭源旗舰模型的定价权构成直接压力。

WAIC 2026：具身智能告别秀场，200+ 企业秀「打工」实力

世界人工智能大会 WAIC 2026 落幕，具身智能展区出现了一个肉眼可见的转变——从「表演」走向「干活」：

  • 规模翻倍：参展企业从去年的 80 余家猛增至 200+，现场真机数量突破 300 台，大会首次开辟 H3 整馆作为具身智能专属展区
  • 画风转向：前几年展馆里机器人翻跟头、跳舞编排，今年变为拆垛、上料、装配。智元机器人 1:1 复刻了广州地铁安检扫描场景，机器人自主完成包裹识别、扫码、分拣、码垛；有的展台搭起缩微版芯片封装产线，机器人双臂配合完成取料、视觉对位到精密装配的全流程
  • 客户关注点变了：不再问「能不能动」，而是问良率多少、CT 节拍多少秒、故障率多低。极智嘉创始人陈曦在论坛上一句话被反复引用：「我们不做 Demo，只做生产力。」

逐际动力展台带来 Luna、Oli、TRON 2 三款产品组成的机器人矩阵，全新发布的 COSA 人形大脑系统搭配自研 WBT 全身运动基础模型；开普勒机器人则展出面向工业场景的重载机器人，其中平板型重载机器人自重 300 公斤、载重近 1 吨，可在非铺装地形完成重型物资运输。

值得关注的原因：这是具身智能行业从「技术验证」走向「商业验证」的拐点信号。当客户开始用工业级可靠性标准（而非新奇感）来验收机器人，意味着行业正进入真正的规模化部署前夜。

银河通用 Galbot：全球首次人形机器人新能源产线常态化自主作业

北京银河通用自研的 WAM-TTT（世界模型测试时后训练）框架近期进入规模化部署阶段。该框架使机器人在部署阶段仅凭少量人类视频即可快速适应新场景，无需重新训练：

  • Galbot G1：已在全家便利店上岗，执行商品补货、货架整理等任务
  • Galbot S1：在宁德时代产线 7×24 小时连续作业超 3 个月，实现全球首次人形机器人新能源产线常态化自主作业

同期，RoboHarness 框架提出异构策略编排新范式——将 VLA、RL、TAMP 等控制策略封装为可调用技能，由 coding agent 进行任务拆解与路由，在 LIBERO-LoHo 长时序任务上将完整成功率提升至 95.2%。美格智能也于 8 月 3 日发布了两款具身智能数据采集解决方案，聚焦多路传感器时间同步、高帧率原始数据采集与多模态融合。

值得关注的原因：3 个月连续产线作业是一个硬指标——它证明人形机器人已能扛住工业级强度的可靠性要求，不再只是展台上的演示品。WAM-TTT 的「测试时后训练」思路也为具身智能的快速场景适配提供了一条不同于大规模重训练的轻量路径。

AI Coding Agent 竞争白热化：GPT-5.6 Sol 与 Claude Opus 5 并驾齐驱

市场侧的数据同样惊人：

  • Cursor：从 $1M 到 $500M ARR 仅用约 24 个月，2026 年 2 月年化收入超 $20 亿，近 70% 的 Fortune 1000 企业在使用，企业收入占比从 25% 升至 60%
  • Claude Code：2025 年 5 月上线，9 个月内年化收入达 $25 亿，占 Anthropic 总收入约 20%；约 4% 的 GitHub 公开 commit 由 Claude Code 生成
  • Codex：周活 300 万，OpenAI 内部 70% 工程师使用，每周合并 PR 数提升 70%

值得注意的是，Cursor 在 7 月发布了与 xAI 联合训练的 Grok 4.5，成为首个由工具厂商参与训练前沿级编码模型的案例——模型与工具不再是可以独立选择的两件事。

值得关注的原因：当头部模型基准分差不到 0.5 分，竞争重心已从「谁的模型更强」转向「谁的工程化体验更好、成本结构更优」。对开发者而言，这意味着选型的关键变量从模型跑分变成了工作流适配度、上下文工程质量和团队协作能力。

Baseten 130 亿美元 F 轮：推理工程成为独立学科

AI 推理基础设施公司 Baseten 完成了一轮 130 亿美元的 F 轮融资，直接跻身 AI 基础设施十角兽阵营。这轮融资传递的信号很明确：推理工程不再是大模型训练完成后「捎带手做的边角料」，而是被资本和产业同时按下了加速键。

Philip Kiely 今年 2 月出版的《推理工程》一书系统回答了一个被长期忽视的问题：如何把训练好的模型权重变成又快、又稳、又省钱的线上产品。Baseten 团队在 GLM-5.2 上跑出了一个反直觉发现——对更多层做量化，不仅没有拉低模型质量，吞吐量反而提升了 20%。原因是不同层引入的量化误差会彼此抵消，误差 A 加上误差 B 居然比误差 A 单独存在时更小。

推理工程正在长出完整的骨架：独立的研究问题、专属的基础设施栈，以及越来越细分的人才岗位。从量化配对到服务架构，每个环节都藏着新的优化空间。

值得关注的原因：当模型能力趋同，推理效率成为新的护城河。Baseten 的「误差抵消」发现说明，推理优化中还有大量反直觉的工程红利尚未被挖掘——这对自建推理基础设施的团队尤其有价值。
