Claude Code 误删 700GB，具身智能核心组件上市

2026-09-01 · 6 min 阅读

发生了什么

9 月 1 日，AI 行业继续围绕”Agent 落地代价”与”具身智能商业化路径”展开。编码 Agent 侧，Claude Code 的一起真实数据丢失事件把”安全机制本身成为风险源”的问题摆上台面；具身智能侧，梅卡曼德登陆港交所，成为首家以核心组件而非整机登陆公开市场的具身智能企业，同时行业对”能不能干活”的验收标准正在从模糊的概念变成可量化的力量、环境、智力三道门槛。

Claude Code 安全降级误删 700GB：给 AI 加的保险成了事故本身

开发者 Sebastien Guillemot 披露，其在使用 Claude Code 的 Fable 5 子 Agent 自动清理 /tmp 垃圾文件时，模型因涉及高风险的硬删除操作，自动触发”降级保护”机制，将任务交给更保守的 Opus 5，随后又降级到 Opus 4.8。问题出在 Opus 4.8 执行清理脚本时复用了存放主目录路径的同一变量，结果把刚被判定”不可删”的用户主目录删掉了约 700GB 数据，而真正该清理的 /tmp 反而完好无损。

这件事的吊诡之处在于：敏感操作自动降级到更保守模型，本意是降低激进误删的概率；但当任务复杂度没有下降、执行者能力却先下降时，弱模型反而犯了变量复用这种低级错误。事后 Guillemot 依靠 git 仓库和会话日志找回了大部分数据。

值得关注的原因：这是 Agentic Coding 工具从”演示风险”进入”真实生产事故”的标志性案例。它提示团队，护栏设计不能只看模型是否更保守，还要看上下文传递、变量隔离和边界检查是否经得起跨模型切换。建议为 Agent 设置显式的删除审批门、使用一次性容器、并默认关闭自动清理钩子。

来源：新浪科技 / Tom’s Hardware / Codeant 安全研究（2026-08-30 至 08-31 综合报道）

Cursor Automations：把 Agent 的启动权从人交给规则

Cursor 近日推出 Automations，允许 Agent 按预设条件自动启动并推进任务，只在必要节点把人拉回决策。官方披露首批场景 Bugbot 已实现每小时数百次自动化触发，并扩展到安全审计、深度审查与事故响应：Agent 可被事件唤醒后自动拉取服务器日志排查。

这等于承认，在多个 Agent 并行的场景下，工程师的注意力已经成为新瓶颈。真正的变化不是省几次点击，而是代码库从”人改的对象”变成持续被模型巡查的系统。代价是审阅压力后移，把关者的带宽并未同步扩容。

值得关注的原因：它标志着 Coding Agent 的竞争焦点从”单次生成质量”转向”长周期自动化治理”，工程团队需要同步建设审计、回滚与审查流程，而不是只给工程师发更多通知。

来源：Cursor 官方产品发布 / 外媒报道（2026 年 8 月下旬）

梅卡曼德港交所挂牌：具身智能”眼脑手”第一股

清华海归团队 2016 年创办的梅卡曼德（09615.HK）今日在港交所主板挂牌，发行价 101.70 港元，预期市值约 127 亿港元，募资额约 23.5 亿港元。基石投资者包括柏基、泰康人寿、Jane Street、比亚迪产业资本与易方达等 9 家，合计认购约 1.86 亿美元，占募资规模约 62%。

梅卡曼德刻意避开整机价格内卷，只做标准化的工业级 3D 视觉、分层机器人大脑与末端执行组件，走”一脑多形”复用路线。截至 2025 年，其全球累计部署约 29000 台，覆盖 50 多类典型场景，海外收入三年复合增速 82.7%，按收入计全球市占率约 22.1%。

值得关注的原因：它是具身智能领域第一家靠核心组件而非整机上市的企业。长线资金同时押注比亚迪产业资本与柏基，说明市场更愿意为”可跨行业复用的上游标准件”买单，而不是为每台都要重新适配的整机故事付费。对开发者而言，这意味着未来做具身应用可能更像搭乐高：视觉、大脑、执行器可以分别选型。

来源：港交所最终发售价及配发结果公告（2026-08-31） / 雷递网（2026-09-01）

具身智能”能不能干活”的三道门：力量、环境、智力

8 月底两场机器人盛会散场后，行业评判标尺明显换挡。工信部人形机器人与具身智能标准化技术委员会委员刘宇龙给出一个朴素框架：能不能干活，看力量、环境适应力与智力三项够不够。此前大量产品重演示轻落地，力量输出与环境适应普遍不足。

关键数据包括：P85MAX-S 关节模组以 1 公斤级重量驱动 90 公斤负载；某四足产品负载自重比达 7:1，可持续背负 16 公斤、静态承载 150 公斤；宽温域覆盖零下 20 至 55℃，支持 40 度爬坡、70 厘米越障、每秒 5 米移动。2026 上半年中国机器人产业规上营收达 1655 亿元，同比增长 24.5%。

值得关注的原因：这套指标把”泛化”这种模糊说法拆成可验收项。力量决定能否接单，环境适应力决定能否走出展厅，智力才真正区分干活与表演。对于在评估机器人方案的团队，这比任何 demo 视频都更值得写入 RFP。

来源：中新网 / 央广网（2026-08-31）

OpenClaw 2.0：开源个人 Agent 的操作系统级竞备

开源个人 AI 助手 OpenClaw 发布 v2026.8.1，团队将其称为”OpenClaw 2.0”，并称这是项目推出以来规模最大的一次更新：933 位贡献者提交了超过 1.6 万个 PR，约占该项目历史合并代码的一半。新版重新设计安装流程，引入 Active Memory、后台记忆整合、Private Credential Request、Automation 一次性授权、第三方插件审计，并支持 Shared Cloud Sessions 与实验性 Swarm 子 Agent。

值得关注的原因：OpenClaw 与 Claude Code、Cursor 的专业级编码定位不同，它更像”数字员工操作系统”。2.0 的方向——长期记忆、跨端续接、多人协作、Swarm 子 Agent——正是当前 Agent 工具的主流演进方向。它的意义在于把”如何让 Agent 跨越单次会话、单一设备保持状态”这件最难的事做了工程化封装；但同时提醒我们，长期记忆一旦沉淀了错误判断，就会跨会话扩散。

来源：OpenClaw 基金会发布说明 / 腾讯研究院日榜（2026-08-31）

一句话总结

Agent 正在从”会不会写代码”进入”能不能放心让它自己跑”的阶段；具身智能则在用核心组件上市和可量化验收标准，回答”除了翻跟头还能干什么”的质疑。
